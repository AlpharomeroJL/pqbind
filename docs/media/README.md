# Media

Images for the README and the repository page. Everything here is generated by the scripts in `scripts/demo-gif/`.

| File | What it is |
|---|---|
| `demo.gif` | A terminal animation of `pqbind demo`: the eight attack scenarios and the summary table. |
| `demo-poster.png` | The last frame of the GIF (the summary table), for places that cannot show a GIF. |
| `demo.transcript.json` | The captured output of a real `pqbind demo` run, one entry per line with the seconds since the process started, plus the exit code (0) and the run time. |
| `demo.transcript.txt` | The same output as plain text. |
| `social-preview.png` | The repository social card, 1280 x 640 px. |

## How the GIF is made

The GIF is a paced replay of the captured output of a real `pqbind demo` run. The text of every line comes from the transcript and is not edited, reordered or added to. Only the timing is synthetic, because the real run takes under a second: lines appear a few at a time, each verdict and note lingers, and the summary table stays on screen for about three seconds. The colors come from simple rules on the text and never change it.

The summary table is 177 columns wide, so when it starts the terminal view zooms out (a smaller font in a wider window) so that every column fits without wrapping.

## Regenerate

You need Python 3 with Pillow, `ffmpeg` on the PATH (for the GIF palette), and the Windows fonts Cascadia Mono and Segoe UI. From the repository root:

```text
cargo build --release -p pqbind-cli
python -I scripts/demo-gif/capture.py PATH_TO_PQBIND_EXECUTABLE    # runs the demo, writes the two transcript files
python -I scripts/demo-gif/render.py                               # writes demo.gif and demo-poster.png
python -I scripts/demo-gif/social.py                               # writes social-preview.png
```

`capture.py` takes the path of the built executable (`pqbind.exe` on Windows) and exits non-zero if the demo does not exit 0. `render.py` refuses a transcript of a failed run, and it can re-render the GIF from the stored transcript without running the demo again. It also takes `--colors` (palette size, default 40), `--group` (lines shown per frame, default 3) and `--work-dir` (where the temporary frames go; default a temporary folder).
