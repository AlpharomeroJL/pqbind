# Contributing

**Code contributions are not accepted yet.** pqbind is offered under two licenses (see [LICENSING.md](LICENSING.md)), so a
contributed change can only be merged under a contributor agreement that lets the copyright holder offer it under both. That
agreement is not in place.

What is welcome:

- Bug reports and questions, as issues.
- Design feedback, especially on the threat model and on the composition of the hybrid signature. See [DESIGN.md](DESIGN.md),
  [THREAT_MODEL.md](THREAT_MODEL.md) and the [reviewer's guide](docs/REVIEW.md).
- Security reports: follow [SECURITY.md](SECURITY.md) rather than opening a public issue.

To run the checks locally, use `scripts/check.sh` (or `scripts/check.ps1` on Windows).
